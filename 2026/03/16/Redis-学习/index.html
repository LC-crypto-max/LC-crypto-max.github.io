Redis 学习笔记

一、Redis简介

Redis（Remote Dictionary Server）是一个 高性能的键值型数据库，常用于：

  • 缓存系统
  • 分布式锁
  • 消息队列
  • 会话存储

特点：

  • 基于 内存存储
  • 支持 多种数据结构
  • 支持 持久化
  • 支持 发布订阅

三、Redis核心数据结构

Redis支持以下几种主要数据结构：

数据结构 说明
String 字符串
List 列表
Set 集合
Hash 哈希
Zset 有序集合
