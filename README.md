[https://lc-crypto-max.github.io](https://lc-crypto-max.github.io)

## 项目说明
本仓库用于备份 Hexo 博客源码，主要包括：

- Hexo 配置文件
- 博客文章源码
- 主题配置
- 页面与资源文件

## 分支说明

- `main`：存放 Hexo 博客源码
- `gh-pages`：存放 Hexo 生成后的静态页面，用于 GitHub Pages 部署
